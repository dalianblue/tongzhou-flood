## 两次淹没事件还原

- **7/13 台风+泄洪型**：台风"巴威"(BAVI/2609) 7/11 深夜正面过境桐洲岛（最近 13km，STS 级），
  水库台风前预泄（坝下 24h 均值 9.76m 全年最高），新桐乡真实峰 7.61m。
  巴威 7/10 距岛 1000km+ 时路径已明确 → 台风预警可提前 48h+
- **8/9 台风外围型**：台风"白海豚"(DOLPHIN/2613) 路径最近 205km（未过境），外围雨带
  致渌渚江支流暴涨（渌渚镇 6h +1.42m），坝下仅 ~8m，新桐乡真实峰 ~7.11m。
  当日 11.31m 读数为传感器故障（下游不可能高于上游 4m），已物理校验剔除

淹没阈值：新桐乡 ≥6.5m 黄 / ≥7.0m 红。

## 台风因素 (typhoon.py)

数据源：中央气象台台风网公开接口（typhoon.nmc.cn，JSONP，无需登录）。

```bash
python3 typhoon.py --harvest   # 一次性收割全年台风轨迹 → data/ (研究样本, 已含)
python3 typhoon.py --live      # 当前活动台风 + 72h预报路径距岛威胁
```

- `--check` 风险卡自动附带台风段：活动台风当前距离 + 各机构 72h 预报路径最小距岛距离
- **预备级（蓝）**：预报 72h 内距岛 ≤500km → 提示"水库大概率预泄 + 支流涨水，提前巡查"。
  不自动改水位风险等级——水库预泄本身已由坝下判据捕捉（泄洪型黄警），且无台风预报
  历史样本可校准升级规则（白海豚 205km 淹 / 美莎克 866km 未淹，纯距离阈值不可靠）
- `--demo` 复盘自动显示"距岛最近台风"列（从收割的轨迹缓存读取，零API）

## 使用

```bash
python3 flood_warning.py --check             # 实况风险卡 (4次API, ~2分钟, 间隔26s限频)
python3 flood_warning.py --backtest          # 样本回测 (零API)
python3 flood_warning.py --demo 2026-08-09   # 事件复盘 (零API)
```

## 规则与回测结果

| 级别 | 判据 |
|---|---|
| 黄-泄洪 | 坝下24h均值≥7.0 且 渌渚6h涨≥0.3 |
| 黄-支流 | 渌渚6h涨≥0.8 / 渌渚镇涨≥1.2 / 山溪涨≥0.6 |
| 红-动量 | 渌渚+6h涨幅 ≥7.3（峰值外推） |
| 红-泄洪级 | 坝下24h均值≥8.6 或 瞬时≥10.0 |
| 顶托 | 闸口≥6.0 时黄升红 |
| 现报级 | 已过淹没阈值则保持不降级 |

回测（6/25~8/31，1609h）：3 次事件全中，首黄提前 19h/15h/48h，首红提前 11h/5h/48h。

阈值校准方法与全年（1~8月）误报扫描详见 pyTides 仓库 `architect.md` A9。
