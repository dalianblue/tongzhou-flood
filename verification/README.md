## 核心结论（详见 REPORT.md）

1. 2025-06-15~17 为真实特大洪水：坝下逐时中位峰 **11.80m**（6/16 11:00）、渌渚 **8.53m**（6/16 12:00）——独立管道精确复现，`0203034` 撤回判定中"量级虚高"部分**过严**；
2. 新桐乡 8.28m 真实存在但为 **6/17 07:00 毛刺小时中位**（6/17 凌晨有 17.86m 瞬时尖峰，前后分钟跳变，窄溪同期仅 8.31m，不合水力学）；6/15 当日真实峰值 **7.27m**（23:45）；
3. 预警算法在正确数据下：6/15 08:00 红级（动量）领先新桐乡淹没红线（22:00）**14 小时**，无漏报；仅 6/14 一次短暂动量误触发（1.5h 自愈）；
4. 官方 5 分历史库 2025-06 干流核心站数据完整可用，可作为样本外验证源。
